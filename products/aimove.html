For developers

Plug deliveries into your platform.

Add AiMove to your own systems with the delivery API, and get status updates through webhooks.

POST /api/v1/deliveries/create
{ "origin": "Lagos", "dest": "Abuja", "weight": 5.0 }

→ 201 { "status": "CREATED", "id": "pkg_1" }

GET  /api/v1/deliveries/{tracking}/track
→ 200 { "status": "IN_TRANSIT", "eta": "25 mins" }

WEBHOOK /api/v1/webhooks/status_update
